# Cite or Delete

Uncited claims are guesses wearing sentences. The evidence standard has
three labels: verified, reported, inferred. Every claim wears one.

- Primary sources for external facts; secondary sources labeled.
- Local claims cite the file and the command output.
- Visual bugs carry a screenshot; flow bugs carry a recording.
- Contradictions are recorded and resolved, never averaged.

Sources: evidence standard; qa-bdd skill.
