# Thin Issues

A thick issue serializes work and hides progress. Thin issues parallelize
and verify one behavior each.

- One wrong behavior per issue.
- Split when fixes are independent.
- Blocked by cites real numbers, filed in dependency order.
- "None - can start immediately" when truly unblocked.

Sources: qa-file skill; issue standard.
