# Report Behavior, Not Code

Issues outlive the code they describe. Write for the reader after the
refactor.

- "The export stops with no message", not a function name.
- Domain language from the codebase glossary.
- Reproduction steps in the user's vocabulary.

Sources: qa-file skill; issue standard.
