### Exploratory pass

**Hunt for unknown bugs under a charter.** Use when the deliverable is a findings report from a bounded exploration session.

Read first: ../qa-explore/SKILL.md, ../qa-file/SKILL.md

1. Write the charter with **qa-explore**: target area, duration, heuristics, stop condition.
2. Run the pass. Record the session on video. Screenshot every finding.
3. Log each finding as observed behavior versus expected behavior.
4. Feed findings into Intake. Reproduce and file with **qa-repro** and **qa-file**.
5. Fan out sweeps to spawned explorers when a spawn tool exists.

**Reply:** findings count, each as one line with severity and media pointer, and the charter verdict.
