# OpenCode adapter

Select skills from the picker, or install through the skills route with
`npx skills add jirayusueb/qa-stack` into a user or project skill
directory.

## Spawning

A task per worker, one subagent per brief, never resumed. Reviewers get
the artifact and the standard only.

## Evidence upload

The tracker CLI attaches files when the host allows it; otherwise the issue
body links `evidence/` paths in the repository.
