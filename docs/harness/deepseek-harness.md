# DeepSeek Harness adapter

The Lead runs the router and the gates. Work fans out as fresh subagents
or as durable teammates.

## Spawning

A subagent per self-contained brief: repro attempts, exploration sweeps,
browser driver work, fresh-context review. Teammates for stage ownership
with disjoint write scopes. The Lead collects artifacts, reviews the final
diff, and runs the checks.

## Evidence upload

The tracker CLI attaches files when the host allows it; otherwise the issue
body links `evidence/` paths in the repository.
