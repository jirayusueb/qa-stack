# Getting started

Five minutes to your first evidence-backed issue.

1. Install the stack. See [the install guide](guide/01-install.md) for
   every route. The quick path:

   ```sh
   npx skills add jirayusueb/qa-stack
   ```

2. Run `/qa-setup` once. It detects the spawn capability, the issue
   tracker, and the browser driver, and records your reply language.

3. Run `/qa-mode` and describe the problem. The router finds where your
   request enters the lifecycle:

   - "The export button does nothing on Safari" enters at Intake.
   - "Why does sync drop the last file" enters at Diagnose.
   - "Is the fix for 412 good" enters at Fix-Verify.
   - "Can we ship 2.4" is Gate.

4. Follow the run. Every stage ends with an artifact: a reproduction with
   video and screenshot evidence, a cited spec, a filed issue, a verified
   fix, or a gate verdict.

Read [the first session guide](guide/02-first-session.md) for a full walk
through, and [the evidence guide](guide/04-evidence.md) for the citation
and media rules every artifact follows.
