# Intake log

Parked reports live here so a new session can resume them. One row per
report. A row leaves when it is filed or withdrawn.

| Report | Open question | Status | Updated |
| --- | --- | --- | --- |
| (example) export button inert on Safari | consistent or intermittent? | parked | 2026-11-08 |

## Rules

- qa-session appends a row when a report parks, and updates it when the
  question resolves.
- A new session reads this log first and names the parked reports before
  taking a new one.
- Filed reports move out with their issue number noted in the run reply,
  not kept here.
